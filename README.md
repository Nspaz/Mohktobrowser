# Mohktobrowser

## One-click mobile browser launcher

This repository now includes `bulletproof-octo-playwright-mobile.ts`, a beginner-friendly automated Playwright launcher that:

- checks required dependencies automatically
- installs Chromium for Playwright automatically
- asks you for the URL you want to open
- shows a colorful terminal loading screen
- opens the page in an iPhone-like mobile browser context

### Run

```bash
npm install
npm start
```
