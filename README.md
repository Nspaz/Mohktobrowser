# Mohktobrowser

Welcome to Mohktobrowser - a delightful web application where you can take and collect mokhs!

## What is a Mokh?

A mokh is a delicious treat waiting to be collected. Each mokh is unique and special!

## Features

- 🍪 Take mokhs with a simple click
- 📚 Build your personal mokh collection
- 💾 Your collection is saved automatically
- 🎨 Beautiful, animated interface

## How to Use

1. Open `index.html` in your web browser
2. Click "Take a Mokh" or click on the mokh directly
3. Watch your collection grow!
4. Click "Browse Mokhs" to view all the mokhs you've collected

## Running Locally

Simply open the `index.html` file in any modern web browser:

```bash
open index.html
```

Or if you prefer using a local server:

```bash
python3 -m http.server 8000
# Then visit http://localhost:8000 in your browser
```

## Technologies Used

- Pure HTML, CSS, and JavaScript
- No frameworks or dependencies required
- LocalStorage for persistence

Enjoy collecting mokhs! 🍪
